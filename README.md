# Stackly Workforce Analytics Intelligence Platform

Enterprise-grade Role-Based Access Control (RBAC) Architecture built with React 18, TypeScript, Redux Toolkit, and Vite.

## 🚀 Key Features

- 🔐 **Granular Role-Based Security**: 5-tier role access model (`ADMIN`, `HR`, `TEAM_MANAGER`, `TEAM_LEAD`, `EMPLOYEE`).
- 🛡️ **Declarative Access Control**: `<RoleGuard>`, `<ProtectedRoute>`, and `usePermission()` hook.
- ⚡ **Interactive Analytics Dashboards**: Real-time charts, employee tables, attendance tracking, and performance metrics.
- 🎨 **Modern Design System**: Dark/Light mode theme engine with responsive glassmorphism aesthetic.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Redux Toolkit, React Router v6
- **Styling**: Vanilla CSS, Lucide Icons, Emotion / MUI Material
- **Build Tool**: Vite 5
- **Charts**: Recharts

## 📥 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
